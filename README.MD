# Micro Shell -> 一款基于单片机进行优化的中型shell驱动库

## 简介
 - 该库基于`GNU C99`标准编写，是一个具有简单功能的可以方便移植的多实例shell库，具有以下亮点
  1. 该库上下层完全解耦，可以很方便地移植到其他地方
  2. 该库仅依赖`fifo`以及`linked-list`两个组件
  3. 该库支持动态增加用户命令，通过构建命令宏，用户的命令解算可以通过几个辅助函数进行状态机选择
  4. 该库支持历史记录，条数以及cache深度都可以调整
  5. 该库支持单独编译，不需要修改c文件即可与其他组件一起使用
  6. 该库支持tab补全
  7. 该库支持返回值显示
